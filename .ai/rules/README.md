# Rules Folder Overview

This folder contains operational project rules used during implementation.

- Start with .ai/rules/index.md for path/task mapping.
- Always load .ai/rules/copilot-instructions.md.
- Load additional rule files based on affected paths and task type.

Folder layout:
- core/: baseline rules that apply broadly.
- frontend/: Blade/Alpine, rendering, UI semantics.
- workflows/: testing and delivery process rules.
- domain/: permissions, approval flow, and state visibility behavior.
